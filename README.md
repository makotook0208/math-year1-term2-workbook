# 中学1年・2学期中間対策 数学問題集

## 使い方

1. 「分野別講義」で解き方と例題を確認します。
2. 「問題演習」で分野を選び、選択式の問題に取り組みます。
3. 答え合わせのあと、正解・不正解にかかわらず解き方を振り返ります。

静的なWebアプリです。ビルドやログインは不要です。学習記録は利用している端末のブラウザに保存され、外部サーバーへ送信されません。

## 内容

- 項と係数: 2問
- 文字式の計算: 22問
- 方程式: 24問
- 比例式: 10問
- 合計: 58問

全問を選択式で回答できます。大問5は複数選択、それ以外は1つ選ぶ形式です。分野別の講義には考え方、手順、例題、確認ポイントを収録しています。

大問12の（5）〜（8）は、解答用紙で確認できた値に合わせた類題です。原本の問題文を復元したものではありません。大問10の（3）は、解答用紙の解説に載っていた式から復元しています。

## ファイル

- `index.html`: アプリ画面
- `styles.css`: 表示とスマートフォン向けレイアウト
- `questions.js`: 問題・正答・ヒント・解説
- `app.js`: 講義、選択式演習、答え合わせ、学習記録
