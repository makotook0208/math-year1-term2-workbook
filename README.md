# 中学1年・2学期中間対策 数学問題集

## 使い方

`index.html` をブラウザで開くと使えます。ビルドやログインは不要です。GitHub Pagesで公開する場合は、このフォルダ内のファイルを公開先へ置いてください。

## 内容

- 項と係数: 2問
- 文字式の計算: 22問
- 方程式: 24問
- 比例式: 10問
- 合計: 58問

大問12の（5）〜（8）は、解答用紙で確認できた値に合わせた類題です。原本の問題文を復元したものではありません。大問10の（3）は、解答用紙の解説に載っていた式から復元しています。

## ファイル

- `index.html`: アプリ画面
- `styles.css`: 表示とスマートフォン向けレイアウト
- `questions.js`: 問題・正答・ヒント・解説
- `app.js`: 演習、答え合わせ、学習記録

学習記録はブラウザのローカルストレージに保存します。外部サーバーへの送信や外部ライブラリの読み込みはありません。
